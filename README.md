## Make it clear. Make it work.

I design and build websites, product experiences, and practical digital systems for founders, operators, and small teams.

Sometimes the problem is the website. Sometimes it's the product, the workflow, or the system behind how the work gets done. I connect **strategy, UX/UI, development, technical SEO, and release QA** so the finished result is easier to understand, use, and run.

One direct partner. No handoff maze between the idea and the shipped result.

### What I work on

| Focus | What that means in practice |
| --- | --- |
| **Strategy + structure** | Offers, information architecture, page purpose, and content hierarchy. |
| **UX/UI + design systems** | Responsive interfaces, accessible states, and reusable components. |
| **Build + performance** | Front-end implementation, discoverability, and durable behavior. |
| **Audit + release QA** | Evidence-led fixes, mobile checks, launch paths, and verification. |

### Four questions I use before polishing a homepage

1. **What do you do?**
2. **Who is it for?**
3. **What problem do you solve?**
4. **Why should somebody choose you?**

If those answers are difficult to find, visual polish will not fix the underlying clarity problem. [Use the Four Questions](https://www.mortenagiraffe.com/four-questions).
